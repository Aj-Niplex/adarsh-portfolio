## Layout
- A title line.
- When to use it.
- Numbered steps.
- Optional notes.

## Synthetic example
```
# Weekly review
Use when: the owner asks for a weekly review.
1. List this week's notes.
2. Summarise in five lines.
3. Save the summary as a note.
```

## Limit
15,000 characters.
